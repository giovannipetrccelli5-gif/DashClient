# DashClient

Fabric client-side HUD and utility mod for Minecraft 26.3 (Java 25).

**26 toggleable modules:** FPS Display, Coordinates, Direction, Clock, Fullbright,
Toggle Sprint, CPS Counter, Armor/Item HUD, Zoom, Performance Boost, Ping,
Memory, Client Uptime, Keystrokes, Potion Effects, Biome, Chunk Position,
Speedometer, Health, Hunger, Totem Counter, Item Count, Item Durability,
World Time, Server Address and Block Info.

Right Shift opens the built-in paginated menu. Hold C to zoom when the Zoom
module is enabled. Keybindings can be changed in Minecraft Controls.

Only FPS and Coordinates are enabled by default. Everything else is optional.
Modules and their on/off states are stored in Fabric's config directory.
The Performance Boost module adjusts local graphics settings and backs up
the original values; no FPS multiplier is promised.

## Get the JAR
Download the latest **development build** from
[GitHub Releases](https://github.com/giovannipetrccelli5-gif/DashClient/releases/tag/dev-build).

Built with GitHub Actions (Java 25, Fabric Loom 1.17). Features are compiled
but still require in-game testing, especially with other performance mods.
